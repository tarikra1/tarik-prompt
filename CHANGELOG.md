# Changelog

All notable changes to `tarik-prompt` are documented in this file.

## [1.1.0] - 2026-11-25

### Added
- Multi-version GitHub Actions CI matrix (`Python 3.10`, `3.11`, `3.12`) testing both unit test suites and CLI compilation entrypoints.
- `CHANGELOG.md` and `SECURITY.md` documentation.
- Release and CI status badges in `README.md`.

## [1.0.0] - 2026-11-25

### Added
- Bilingual (`English` / `Arabic`) `SKILL.md` prompt optimization package supporting `BASIC` and `DETAIL` diagnostic modes.
- Model-specific blueprint compiler (`tarik_prompt.compiler`) targeting Claude semantic XML tags, ChatGPT Markdown context layering, and Gemini multimodal schemas.
